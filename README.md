QuickSight – Vision Practice Management Demo
Overview

QuickSight is a web-based demonstration application designed to simulate common workflows found in an optometry practice. The project was created to showcase front-end web development, user interface design, and the integration of healthcare-related data in an interactive environment.

The application demonstrates how patients can navigate through a modern vision practice website, register for services, and view simulated insurance information. It was built as a portfolio project to apply programming concepts learned through an Associate of Applied Science in Computer Programming.

Features
Responsive multi-page website
Patient registration interface
Login and sign-up pages
Simulated insurance verification using JSON data
Sample vision insurance plans (VSP and EyeMed)

Purpose

This project was developed to demonstrate practical web development skills by recreating workflows commonly used in healthcare practices. It focuses on creating an intuitive user experience while organizing information in a clear and accessible way.

The insurance verification feature uses sample data to simulate how a patient portal or front desk application might display vision insurance benefits.
